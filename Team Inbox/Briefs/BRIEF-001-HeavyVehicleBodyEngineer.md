## 1. Role Summary

A Heavy Vehicle Body Engineer specialising in tanker construction designs, specifies, and certifies liquid bulk bodies mounted on commercial truck chassis. In the transport sector this person sits at the intersection of structural engineering, dangerous goods compliance, and chassis integration. They are the person responsible for ensuring the body does not destroy the chassis and the chassis can support the body — legally, structurally, and operationally.

---

## 2. Core Knowledge Domains

| Domain | Detail |
|--------|--------|
| Chassis integration | Reading and applying OEM Body Builder Instructions (BBI); understanding chassis rail profiles, cross member spacing, permitted mounting zones, torque tube constraints |
| Subframe engineering | When subframes are required; subframe geometry; mounting methods (clamped, bolted, welded); material selection; cross member design and placement |
| Load engineering | GVM, GCM, axle load distribution, centre of gravity calculations for liquid bulk; liquid surge and dynamic load effects |
| Tanker construction | Shell design (cylindrical, elliptical, rectangular); baffle placement; manhole and inspection access; outlet valve positioning; internal coatings |
| Dangerous goods compliance | ADG Code (7th Edition); Class 3 flammable liquid requirements; AS 2809 (Road tank vehicles for dangerous goods); static electricity, bonding and earthing for Class 3 fuels |
| Australian Design Rules | ADR compliance for heavy vehicle modifications; NHVR requirements for PBS (Performance Based Standards) where applicable |
| Materials engineering | Structural steel grades (350, 450); aluminium alloys (5083, 5052) for tank shells; stainless steel for food/chemical grade; welding standards (AS/NZS 1665, AS/NZS 2980) |
| Hydraulics and fluid systems | Pump selection, piping layout, pressure/vacuum relief, bottom loading/top loading configurations |
| Workplace and fabrication standards | Workshop supervision, weld inspection, non-destructive testing (NDT) for tank shells |

---

## 3. Day-to-Day Tasks

- Reading chassis OEM BBI documentation and extracting mounting constraints
- Calculating subframe dimensions, cross member positions, and material specifications
- Performing axle load calculations and weight distribution analysis
- Drafting fabrication drawings (subframe, tank shell, pipework)
- Writing compliance documentation for ADG Code and AS 2809
- Liaising with chassis dealers and OEM technical support
- Supervising fabrication in workshop environments
- Specifying and sourcing materials (structural steel, aluminium, fittings)
- Conducting or commissioning tank pressure/leak testing
- Preparing NHVR modification plates and documentation

## 4. Tools, Frameworks, and Standards

| Category | Specifics |
|----------|-----------|
| OEM documentation | Volvo Body Builder Instructions (BBI), Isuzu BBI, Kenworth BBI |
| Australian standards | AS 2809 (Road tank vehicles for dangerous goods), AS/NZS 1665 (Welding of aluminium), AS/NZS 2980 (Welding of steel) |
| Dangerous goods | ADG Code 7th Edition — Chapter 6 (tank requirements), Class 3 provisions |
| Regulatory | NHVR Heavy Vehicle National Law (HVNL); ADR series |
| Design software | SolidWorks, AutoCAD, Inventor (common in fabrication shops) |
| Load calculation | Spreadsheet-based axle load tools; some OEM load calculation portals |
| Certifying authority | NHVR Approved Vehicle Examiner (AVE) or relevant state authority for modification plates |

## 6. Sub-Specialisations — Worth Noting

| Sub-specialisation | Separate hire? |
|--------------------|----------------|
| Petroleum / fuel tankers (Class 3) | Core of this brief — one hire covers this |
| Chemical tankers (Class 6, 8) | Similar skills; different lining and valve specs — could be same hire if cross-trained |
| Food grade tankers | Different compliance regime (HACCP); likely separate if volume warrants |
| Cryogenic / LNG tankers | Distinct engineering domain — separate hire if required |
| PBS (Performance Based Standards) vehicle design | Specialist overlay — add if fleet runs PBS-registered vehicles |

**Recommendation:** One hire covers Class 3 petroleum tankers and can extend to Class 6/8 chemical with minimal upskilling. Food grade and cryogenic are separate domains.

---

## 7. Felix's Notes

This role has a compliance backbone — AS 2809 and the ADG Code are non-negotiable for Class 3 fuel tankers. The candidate must be able to work from Volvo's BBI documentation without hand-holding. Subframe and cross member specification is a core daily task, not a specialist overlay.

The domain is well-defined. I recommend a single hire at this stage covering Class 3 petroleum tanker construction on rigid truck chassis.
